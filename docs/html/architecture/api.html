API Reference

All endpoints are Next.js App Router route handlers under app/api/. Admin routes are guarded by proxy.ts (session) plus in-handler verifyRole([...]).…

  • Pagination on list routes uses page + limit query params (limit capped, e.g. 25–100).
  • Search on applications/talent uses search and is passed through sanitizeSearch().
  • Write routes that need the created/updated row call .select().single() on the query builder to get it back.
