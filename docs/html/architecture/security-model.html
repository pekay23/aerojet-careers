Architecture

Security Model

Authentication and authorization are handled entirely in the application layer (no Supabase Auth, no Row Level Security).

  • Tokens are single-use: consuming them deletes the row immediately.
  • TTL is SESSION_MAX_AGE * 30 / 7 days (configurable in lib/refresh-token.ts).
  • Implemented in lib/refresh-token.ts; rotation happens automatically on /api/auth/refresh.
