05 · Stack at a glance

Stack at a glance

  • Frontend: Next.js 16 (App Router), React 19, Tailwind CSS 4, shadcn/ui + Radix, Framer Motion
  • Backend: Next.js API routes (serverless)
  • Database: PostgreSQL (Neon, primary) via pg + a Supabase-compatible query builder; Supabase retained as secondary/backup
  • Auth: Local bcrypt + JWT session cookie (replaced Supabase Auth)
  • Storage: storage_objects table served through /api/files (replaced Supabase Storage)
  • Email: Resend
  • Hosting: Vercel (region lhr1), edge route guard in proxy.ts
06 · Rebuilding the HTML mirror

Rebuilding the HTML mirror

bun run docs:html      # or: node scripts/build-docs-html.mjs

This regenerates every .md under architecture/ and guides/ into a styled HTML page at docs/html/<section>/<slug>.html, plus a docs/html/index.html linking them all. Internal .md links are rewritten to .html automatically. The generator lives at scripts/build-docs-html.mjs and uses marked; it writes its own design-tokens.css + docs.css into docs/html/, so there are no external dependencies. Open docs/html/index.html to browse.
